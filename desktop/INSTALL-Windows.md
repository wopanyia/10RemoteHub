# Windows 安装与使用

从 `0.3.0` 起，所有遥控器都在「我的遥控器 → 添加遥控器」接入：试按一次，App 告诉你属于哪一档（✅ 直接接入 / 🔧 点一下就能接入 / ⚠️ 目前无法自动接入 / ❓ 看不到设备），再导入正面照片学键。按设备分三种情况：

- **通用 USB / 蓝牙 HID 遥控器**：免装驱动，解压即用。语音键触发识别软件，使用电脑麦克风。
- **系统读不全的 USB 接收器（如配套 `0416:0602`）**：在添加窗口点「让 App 接管这个接收器」，App 换上 Windows 自带的 WinUSB 驱动，不需要 Zadig。`0416:0602` 接管后才能读到 `#` 键和遥控器麦克风。
- **Windows 自带蓝牙读不了的 BLE 遥控器**（设备管理器里报错误代码 10，如 `0416:0300`）：插一只外接 USB 蓝牙棒，在添加窗口一键切换为直连模式，读取全部按键和遥控器麦克风。

使用遥控器麦克风时需要 **VB-CABLE**（虚拟声卡，不随本项目分发，需向原提供者获取）。应用支持多显示器高分屏 Per-Monitor V2 DPI 缩放。

> 发布包位于 [GitHub Releases](https://github.com/yizhixiaoheigou/10RemoteHub/releases)。先核对同一版本的 `SHA256SUMS`；源码环境与构建见 [RELEASE.md](RELEASE.md)。

> Windows 11 x64 已实机验证：`0416:0602` 的软件内一键接管接收器（`0.3.1`）、全键位、遥控器麦克风与九键拼音输入；经外接蓝牙棒 `0BDA:8771` 直连 `0416:0300` 的按键与实时语音（`0.3.0`）。非 `0416:0602` 未知 USB 接收器的 15 秒自动回退与通用共享 HID 原按键屏蔽待更多样机复测。

## 一、准备驱动与音频组件（按设备按需准备）

### 1. 让 App 接管接收器（`0416:0602` 或系统读不全的接收器）

> **重要前置条件（0416:0602 全新安装必读）**：没让 App 接管时，系统只能经 Raw Input 降级读取，收不到 **`#` 号键**和遥控器麦克风。**首次添加 `0416:0602` 时，先在添加窗口点「让 App 接管这个接收器」，重新插拔一次接收器并点「重新检测」，再导入照片学键。** 普通 USB / 蓝牙 HID 遥控器不需要切换驱动，切勿替换鼠标、键盘或其他蓝牙设备驱动。

遥控器的接收器（`0416:0602`）是复合 USB 设备，其中两个关键接口需要交给本项目通过 WinUSB 独占读取：

- **Interface 3（语音接口）**：负责遥控器麦克风音频流与语音键握手；
- **Interface 4（全键位接口）**：负责完整原始按键报文（含 Raw Input 会丢弃的 `#` 号键，并避免按键向系统键盘重复触发）。

**推荐：在 App 里一键接管**（使用 Windows 自带、微软已签名的 `winusb.inf`，不用另装软件）：

1. 插上接收器，打开「我的遥控器 → 添加遥控器」并选中它（检测列表里没有的接收器，也可以在「没检测到」里选）；如果已添加过遥控器，也可以直接在「完成设置」清单或「通用设置 → 设备连接」操作。
2. 点「让 App 接管这个接收器」，在 Windows 弹出的管理员授权里点「是」。App 按接口用途自己决定接管哪些部分：键盘、媒体键和厂商数据接口会接管，鼠标指针、声卡和存储接口不碰。完成后如按键暂无响应，重新插拔一次接收器。
3. 安全保护：接管普通未知 USB 接收器时，电脑上没有别的键盘会拒绝接管，且接管后 15 秒内要点「保留接管」，否则自动恢复原驱动，防止误选键鼠接收器。
4. 接管后，App 没有运行时这只遥控器不能用。想还原时，在添加窗口或「通用设置 → 由 App 接管的接收器」点「恢复系统驱动」。

**备选：用 Zadig 手动绑定**（一键接管失败或需要手动排查时，仅 `0416:0602`）：

1. 从 [zadig.akeo.ie](https://zadig.akeo.ie/) 下载 Zadig（本项目不附带）。
2. 插上遥控器接收器。
3. 打开 Zadig → 菜单 **Options → List All Devices** 打勾。
4. 下拉框里选 **`… (Interface 3)`**，目标驱动选 **WinUSB**，点 **Replace Driver**，等待完成。
5. 再选 **`… (Interface 4)`**，同样选 **WinUSB**，点 **Replace Driver**。
6. 首次换完驱动后，**重新插拔一次 USB 接收器**，在应用「通用设置 → 设备连接」点「重新检查权限与连接」，确认 `USB 0416:0602` 显示为 **已接管** 且连接状态正常。

> 只绑这两个即可。Interface 1/2 会由应用自动尝试顺带接管；即使 Interface 4 暂未绑定，应用也会自动降级到 Raw Input 提供除 `#` 键外的普通按键。

### 2. 外接 USB 蓝牙棒（仅 Windows 自带蓝牙读不了的 BLE 遥控器）

有些电视盒蓝牙遥控器能和电脑配对，但 Windows 的蓝牙驱动拒绝读取它的按键（设备管理器里报错误代码 10）。这时用一只外接 USB 蓝牙棒，由 App 直接和遥控器通信，不影响电脑自带蓝牙。已验证的蓝牙棒：`0BDA:8771`。

1. 插上蓝牙棒，打开「添加遥控器」，在列表里选中这只遥控器（会标着「自带蓝牙无法读取，需要外接蓝牙棒」）。
2. 在下方蓝牙棒卡片点「切换为 BLE 直连模式」，Windows 弹出管理员授权时点「是」。只切换外接蓝牙棒，主板自带蓝牙不会被改动。
3. 长按遥控器的配对键让灯快闪，点「扫描 BLE 遥控器」。扫描只找你选中的那只遥控器，附近其他蓝牙设备（如耳机、相机）不会被连接；找到后自动配对并开始试按。
4. 之后照常导入照片学键；遥控器有麦克风的，在照片上标出语音键即可使用遥控器麦克风。
5. 想把蓝牙棒改回普通蓝牙，在同一张卡片点「恢复普通蓝牙」。

没有选中任何遥控器就点扫描时，App 只自动连接明确是遥控器的设备；只是「可能是」的设备会列出来，由你确认后点「开始检测」。

### 3. VB-CABLE（虚拟麦克风，可选）

仅在将语音来源设为「遥控器麦克风」时需要安装：

1. 从 [vb-audio.com/Cable](https://vb-audio.com/Cable/) 下载 `VBCABLE_Driver_Pack43.zip`（应用「语音设置 → 前往下载 VB-CABLE」即打开此页面）。
2. 解压，**右键 `VBCABLE_Setup_x64.exe` → 以管理员身份运行** → 点 **Install Driver**。
3. **重启电脑**。

装完后系统里会出现：

- 播放端 `CABLE Input (VB-Audio Virtual Cable)`
- 录音端 `CABLE Output (VB-Audio Virtual Cable)`

> 若您的电脑安装了多条虚拟音频线（如 `VB-Audio Cable A/B` 或带前缀的多实例），可在「语音设置 → 虚拟声卡播放端」下拉框中指定目标播放端，程序在录音临时切换默认麦克风时会自动配对同组的 `CABLE Output` 录音端。

## 二、安装与日常使用

1. 下载发布页的 `10RemoteHub-<版本>-win-x64.zip`，解压到固定目录（例如 `D:\10RemoteHub`）。
2. 双击 `10RemoteHub.exe`。若 SmartScreen 拦截，先核对下载来源与该版本的 SHA-256；确认后按系统提供的选项继续。重复双击 `10RemoteHub.exe` 会自动唤醒已运行的托盘实例（并保持原窗口最大化状态）。
3. 首次打开会进入「我的遥控器 → 添加遥控器」流程（从 `0.2.0` 升级时会自动迁移原 `0416:0602` 配置，不需重新添加）：
   - 所有遥控器（含 `0416:0602`）走同一流程：选择对应设备 →「开始检测」→ 试按确认按下与松开后点「导入照片，开始学习」。遥控器有麦克风时先在照片上点一下语音键的位置，再逐个点按键位置并按实体键学键，最后保存。新遥控器默认按硬件 ID 命名（如「遥控器 0416:0602」），可随时改名。`0416:0602` 请先让 App 接管，否则学不到 `#` 号键；若同一只遥控器同时支持 USB 接收器与蓝牙双模，后续在卡片点「学习更多按键」切换另一接收端并试按验证，即可并入同一只遥控器。
   - 保存后会弹出「还差几步」清单，列出必须完成与可选的项目（如接管接收器、虚拟麦克风），点对应按钮即可。
4. **选择应用与进阶能力**：
   - 在「打开 / 收起 App」、「应用专属层」或「自动聚焦聊天输入框」中选择程序时，系统会自动扫描开始菜单、桌面、`%LOCALAPPDATA%\Programs` 官网 `.exe` 安装目录及 MSIX 应用包（如 Kimi、ChatGPT / Codex、Claude、Cursor、微信、豆包、Windows 终端等），支持通过 **从已安装软件添加…** 搜索点选或 **选择本地 EXE…** 任意指定。
   - Windows 版现已支持 **自动聚焦聊天输入框**（通用设置开启并勾选目标聊天软件）、**界面控件动作**（默认支持「自动识别切到的前台软件」，鼠标悬停约 1 秒自动捕获按钮或滚动区）与 **应用菜单命令**（支持传统 Win32 菜单栏与现代 UI Automation 菜单栏），无需管理员权限。

## 三、配置语音

1. 打开 **语音设置**：
   - 语音来源：**遥控器麦克风**（或 **仅触发识别**）
   - 麦克风连接方式：**录音时切换系统默认麦克风**（推荐）
   - 识别快捷键：设成识别软件里“按住说话”用的键
   - 语音前聚焦（可选）：若在通用设置开启了「自动聚焦聊天输入框」，可联动按语音键前先把光标定位回聊天输入框。
2. `0416:0602`：打开 **通用设置 → 设备连接**，确认 `USB 0416:0602` 显示 **已接管**（如显示「未接管」或「部分接管」，直接点「让 App 接管这个接收器」）。蓝牙棒直连的遥控器：语音设置里显示「已连接」即可，按遥控器任意键可唤醒连接。

### 识别软件怎么设

| 识别软件 | 能否用本项目唤醒 | 说明 |
|---|---|---|
| **微信输入法** | ✅ | 识别快捷键设 `Alt`；麦克风选 **系统默认** |
| 豆包输入法 | ❌ | 会过滤所有程序模拟的按键，遥控器无法唤醒 |
| Windows 语音输入（Win+H） | 能唤出，但不识别本项目音频 | 不推荐 |

用「录音时切换系统默认麦克风」时，程序会在按住语音键期间把系统默认麦克风临时切到配对的 `CABLE Output`，松手立刻恢复原设备。因此识别软件的麦克风保持「系统默认」即可。若改为「固定使用虚拟麦克风」，则在识别软件里直接选择 `CABLE Output (VB-Audio Virtual Cable)`。

## 四、已知限制与权限边界

- **不同接入通道对原按键的影响**：App 接管的接收器和蓝牙棒直连的遥控器由本项目独占读取，原键不会向系统重复触发。通过系统共享通道读取的通用 USB / 蓝牙 HID 遥控器，App 运行时按设备拦截已学按键的原功能；但管理员权限的前台窗口不受拦截（见下一条），需要彻底独占时请让 App 接管接收器。
- **蓝牙棒语音体验**：经蓝牙棒的遥控器语音已实时送达识别软件，但实测识别体验仍不如 macOS 上的 USB 遥控器，原因尚未定位。
- **管理员窗口（UIPI 权限隔离）**：当 `10RemoteHub` 以普通用户权限运行时，Windows 用户界面特权隔离（UIPI）会阻止向“以管理员身份运行”的前台窗口（如管理员终端、任务管理器等）发送模拟按键或执行 UI Automation 操作。此时「通用设置 → 系统输入隔离」会给出明确提示。
- **豆包输入法无法被唤醒**：受其自身反模拟按键策略限制，非本项目故障。

## 五、卸载

1. 右键托盘图标退出程序，删除解压目录（若开启过「登录后自动启动」，先在通用设置中关闭，或删除当前用户 `Run` 注册表项中的 `10RemoteHub`）。
2. 删除程序前，先在「通用设置 → 由 App 接管的接收器」点「恢复系统驱动」，并在添加窗口的蓝牙棒卡片点「恢复普通蓝牙」（如用过）。
3. 已经删除程序、或当初用 Zadig 绑定的：设备管理器 → 找到遥控器接收器对应的 `Interface 3` / `Interface 4` → 右键卸载设备 → 勾选「删除此设备的驱动程序软件」，再拔插接收器，Windows 会自动恢复系统默认 HID 驱动。
4. VB-CABLE 可用其安装目录里的 `VBCABLE_Setup_x64.exe`（管理员）移除，或从系统「已安装的应用」卸载。

## 六、出问题看这里

- 连接日志：`%LOCALAPPDATA%\RemoteHub\logs\connection.log`；聊天聚焦日志：`%LOCALAPPDATA%\RemoteHub\logs\chat-focus.log`；蓝牙棒直连日志：`%LOCALAPPDATA%\RemoteHub\ble-dongle\session.log`（记录扫描、连接与语音时序，不含按键内容和录音）
- 只读环境报告：`10RemoteHub.exe --diagnose report.json`
- 最小环境报告：`powershell -ExecutionPolicy Bypass -File scripts\collect_windows_logs.ps1`（源码目录内使用，不含用户名、序列号或个人路径）。
- 更细的架构、协议与验收记录见 [Windows 端说明](docs/WINDOWS-TESTING.md)。
